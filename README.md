# PINAKA CTF Writeups

This repository contains writeups for 40 PINAKA CTF challenges. Each challenge has its own folder with the writeup and any screenshots or supporting files. Folders are grouped by challenge type.

- [Challenge index](00_INDEX.txt)
- [Browse all challenge folders](Challenges/)
- [Writeups shortcut](Writeups/)

The `index.txt` file is a shortcut to `00_INDEX.txt`. The `Writeups/` folder is a shortcut to `Challenges/`.
